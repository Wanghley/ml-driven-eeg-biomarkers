# DBS Artifact Removal Methods - Comprehensive Guide

## Overview

This document describes five advanced DBS artifact removal methods implemented in the preprocessing pipeline. Each method offers different strengths in attenuating DBS harmonics while preserving endogenous brain activity.

Baseline-Referenced Wiener Filter\n\n### Theory\nUses a clean baseline recording (no DBS) to build a frequency-dependent gain mask. The filter adapts in time and frequency to remove only the excess power introduced by DBS while preserving endogenous brain activity at the same frequencies.\n\n**Gain formula:**\n$$G(f,t) = \\frac{P_{\\text{baseline}}(f)}{P_{\\text{baseline}}(f) + \\alpha \\cdot \\max(0, |X(f,t)|^2 - P_{\\text{baseline}}(f))}$$\n\n### Usage\n\n```python\nfrom src.filters import BaselineReferencedFilter\n\n# Apply filter\nwiener_filter = BaselineReferencedFilter(\n    baseline_raw=raw_clean_baseline,  # Clean reference recording\n    dbs_freq=7.0,                     # Fundamental DBS frequency (Hz)\n    harmonic_bandwidth=1.5,           # Width around each harmonic (Hz)\n    n_fft=4096,                       # FFT size for frequency resolution\n    floor_db=-40.0,                   # Minimum gain (-40 dB = 99.99% removal)\n    alpha=1.5                         # Oversubtraction factor\n)\nraw_clean = wiener_filter.filter(raw_dbs)\n```\n\n### Pros\n- ✓ Excellent preservation of endogenous brain activity\n- ✓ Time-varying adaptation to non-stationary artifacts\n- ✓ Natural interpretation: removes only excess power above baseline\n\n### Cons\n- ✗ Requires clean baseline recording (e.g., pre-DBS or same state)\n- ✗ Moderate harmonic attenuation (~20-30 dB)\n- ✗ Assumes similar signal characteristics across states\n\n### Tuning for Stronger Attenuation\n```python\n# Increase alpha (more aggressive subtraction)\nwiener_filter = BaselineReferencedFilter(\n    baseline_raw=raw_baseline,\n    dbs_freq=7.0,\n    alpha=2.0,           # Was 1.5\n    floor_db=-60.0,      # Was -40.0 (stronger minimum attenuation)\n    harmonic_bandwidth=1.0  # Narrower band for more focused filtering\n)\n```\n\n### Best For\n- Research requiring optimal preservation of brain rhythms\n- Situations where baseline recordings are available\n- Analysis requiring time-resolved artifact dynamics\n\n---\n\n## 2. Spectrum-Fit Multi-Harmonic Removal\n\n### Theory\nApplies frequency-domain gain mask using STFT (Short-Time Fourier Transform). The gain smoothly tapers from 1.0 (no filtering) outside harmonics to a target attenuation within harmonics, maintaining spectral continuity.\n\n**Key features:**\n- Smooth cosine rolloff at harmonic band edges\n- Linear attenuation target across all harmonics\n- Preserves phase relationships\n\n### Usage\n\n```python\nfrom src.preprocessing import EEGPreprocessor\n\npreprocessor = EEGPreprocessor(input_dir=\"data/XU/\", output_dir=\"data/processed/\")\n\n# Method 1: Direct call\nraw_clean = preprocessor.remove_artifacts_spectrum_fit(\n    raw_dbs,\n    f_target=7.0,              # Fundamental frequency (Hz)\n    bandwidth=2.0,             # Total bandwidth around each harmonic (Hz)\n    attenuation_db=-60.0       # Target attenuation level (dB)\n)\n\n# Method 2: Via advanced interface\nraw_clean = preprocessor.remove_artifacts_advanced(\n    raw_dbs,\n    method='spectrum_fit',\n    f_target=7.0,\n    bandwidth=2.0,\n    attenuation_db=-60.0\n)\n```\n\n### Parameters\n| Parameter | Default | Range | Description |\n|-----------|---------|-------|-------------|\n| `f_target` | - | 1-100 Hz | Fundamental DBS frequency |\n| `bandwidth` | 2.0 | 0.5-5.0 Hz | Total bandwidth around each harmonic |\n| `attenuation_db` | -60.0 | -30 to -100 dB | Target attenuation (more negative = stronger) |\n| `chunk_sec` | 10.0 | 1-60 | STFT window duration (seconds) |\n\n### Pros\n- ✓ Very strong harmonic attenuation (up to 100 dB possible)\n- ✓ Simple, interpretable parameters\n- ✓ Fast computation\n- ✓ No baseline required\n\n### Cons\n- ✗ May over-attenuate if bandwidth too wide\n- ✗ Affects all harmonics equally\n- ✗ Less adaptive than Wiener approach\n\n### Tuning for Different Scenarios\n\n**Scenario 1: Maximum Attenuation**\n```python\nraw_clean = preprocessor.remove_artifacts_spectrum_fit(\n    raw_dbs,\n    f_target=7.0,\n    bandwidth=1.5,          # Narrower band\n    attenuation_db=-80.0    # Stronger attenuation\n)\n```\n\n**Scenario 2: Softer, More Natural**\n```python\nraw_clean = preprocessor.remove_artifacts_spectrum_fit(\n    raw_dbs,\n    f_target=7.0,\n    bandwidth=3.0,          # Wider band with smoother transition\n    attenuation_db=-40.0    # Lighter attenuation\n)\n```\n\n### Best For\n- Quick, strong artifact removal\n- Cases without baseline data\n- Consistent DBS frequencies across subjects\n- Clinical data requiring reproducible results\n\n---\n\n## 3. Zapline+ (Chen et al., 2022)\n\n### Theory\nAdaptive notch filtering using spectro-spatial decomposition. Identifies the artifact subspace across channels via eigendecomposition of the covariance matrix at each harmonic, then projects and removes this subspace.\n\n**Algorithm:**\n1. STFT decomposition\n2. For each harmonic, build covariance matrix across channels\n3. Eigendecomposition to identify artifact subspace\n4. Project onto artifact space and scale down by removal factor\n5. ISTFT reconstruction\n\n### Usage\n\n```python\npreprocessor = EEGPreprocessor(input_dir=\"data/XU/\", output_dir=\"data/processed/\")\n\n# Method 1: Direct call\nraw_clean = preprocessor.remove_artifacts_zapline(\n    raw_dbs,\n    f_target=7.0,              # Fundamental frequency (Hz)\n    n_harmonics=10,            # Number of harmonics to process\n    threshold_percentile=95.0  # Sensitivity threshold\n)\n\n# Method 2: Via advanced interface\nraw_clean = preprocessor.remove_artifacts_advanced(\n    raw_dbs,\n    method='zapline',\n    f_target=7.0,\n    n_harmonics=10,\n    threshold_percentile=95.0\n)\n```\n\n### Parameters\n| Parameter | Default | Range | Description |\n|-----------|---------|-------|-------------|\n| `f_target` | - | 1-100 Hz | Fundamental DBS frequency |\n| `n_harmonics` | 10 | 1-20 | Number of harmonics to filter |\n| `threshold_percentile` | 95.0 | 80-99 | Percentile for spatial filtering (higher = more selective) |\n| `chunk_sec` | 2.0 | 0.5-10 | STFT window duration |\n\n### Pros\n- ✓ Spectro-spatial filtering leverages multi-channel correlation\n- ✓ Adaptive removal relative to artifact strength\n- ✓ Preserves non-artifact synchrony across channels\n\n### Cons\n- ✗ Higher computational cost\n- ✗ Requires good channel correlation\n- ✗ Less interpretable than frequency-domain methods\n\n### Tuning for Stronger Attenuation\n\n```python\n# More selective: increase threshold_percentile\nraw_clean = preprocessor.remove_artifacts_zapline(\n    raw_dbs,\n    f_target=7.0,\n    n_harmonics=15,           # More harmonics\n    threshold_percentile=98.0 # More selective\n)\n```\n\n### Best For\n- Multi-channel research recordings\n- Cases where spatial patterns matter\n- Systems with high channel correlation\n- Advanced analysis requiring spectro-spatial separation\n\n---\n\n## 4. Frequency-Domain Hampel Filter (Allen et al., 2010)\n\n### Theory\nDetects spectral peaks (like DBS harmonics) using rolling median and Median Absolute Deviation (MAD), then scales down peak magnitudes while preserving phase.\n\n**Algorithm:**\n1. Compute FFT\n2. Apply rolling median to magnitude spectrum\n3. Compute MAD to identify outliers\n4. Scale down outlier magnitudes\n5. Inverse FFT\n\n### Usage\n\n```python\npreprocessor = EEGPreprocessor(input_dir=\"data/XU/\", output_dir=\"data/processed/\")\n\n# Method 1: Direct call\nraw_clean = preprocessor.remove_artifacts_freq_hampel(\n    raw_dbs,\n    window_hz=2.0,            # Frequency window for rolling median (Hz)\n    n_sigmas=3.0,             # MAD sensitivity (higher = more selective)\n    attenuation_db=-60.0      # Target attenuation (dB)\n)\n\n# Method 2: Via advanced interface\nraw_clean = preprocessor.remove_artifacts_advanced(\n    raw_dbs,\n    method='hampel_freq',\n    window_hz=2.0,\n    n_sigmas=3.0,\n    attenuation_db=-60.0\n)\n```\n\n### Parameters\n| Parameter | Default | Range | Description |\n|-----------|---------|-------|-------------|\n| `window_hz` | 2.0 | 0.5-5.0 Hz | Window for rolling median |\n| `n_sigmas` | 3.0 | 1.0-6.0 | Sensitivity threshold (σ in MAD) |\n| `attenuation_db` | -60.0 | -30 to -100 dB | Attenuation level for detected peaks |\n\n### Pros\n- ✓ Excellent for sharp, well-defined peaks\n- ✓ Preserves phase relationships\n- ✓ Adaptive detection of peaks\n- ✓ Fast computation\n\n### Cons\n- ✗ Sensitive to MAD threshold tuning\n- ✗ May miss broad artifact features\n- ✗ Requires FFT (global transform)\n\n### Tuning Recommendations\n\n**More Selective (fewer false positives):**\n```python\nraw_clean = preprocessor.remove_artifacts_freq_hampel(\n    raw_dbs,\n    window_hz=3.0,      # Wider window\n    n_sigmas=5.0,       # Higher threshold\n    attenuation_db=-40.0 # Lighter attenuation\n)\n```\n\n**More Aggressive (stronger removal):**\n```python\nraw_clean = preprocessor.remove_artifacts_freq_hampel(\n    raw_dbs,\n    window_hz=1.0,      # Narrower window\n    n_sigmas=2.0,       # Lower threshold\n    attenuation_db=-80.0 # Stronger attenuation\n)\n```\n\n### Best For\n- DBS with stable, narrow harmonics\n- Quick, robust artifact screening\n- Clinical applications\n- Real-time or batch processing\n\n---\n\n## 5. Time-Domain Hampel Filter (Allen et al., 2010)\n\n### Theory\nDetects and removes impulsive artifacts (like DBS pulses) in time domain. Uses rolling median and MAD to identify samples that deviate significantly from local trends, replacing them with the median.\n\n**Algorithm:**\n1. Compute rolling median\n2. Compute MAD of deviations\n3. Identify outliers (samples with deviation > threshold)\n4. Replace outliers with rolling median or blend\n\n### Usage\n\n```python\npreprocessor = EEGPreprocessor(input_dir=\"data/XU/\", output_dir=\"data/processed/\")\n\n# Method 1: Direct call\nraw_clean = preprocessor.remove_artifacts_time_hampel(\n    raw_dbs,\n    window_sec=0.2,            # Time window for rolling median (seconds)\n    n_sigmas=3.0,              # MAD sensitivity\n    attenuation_factor=1.5     # Removal strength (>1 = multiple passes)\n)\n\n# Method 2: Via advanced interface\nraw_clean = preprocessor.remove_artifacts_advanced(\n    raw_dbs,\n    method='hampel_time',\n    window_sec=0.2,\n    n_sigmas=3.0,\n    attenuation_factor=1.5\n)\n```\n\n### Parameters\n| Parameter | Default | Range | Description |\n|-----------|---------|-------|-------------|\n| `window_sec` | 0.2 | 0.05-0.5 sec | Time window for median |\n| `n_sigmas` | 3.0 | 1.0-6.0 | Sensitivity (σ in MAD) |\n| `attenuation_factor` | 1.0 | 0.5-5.0 | Pass multiplier (>1 for stronger removal) |\n\n### Pros\n- ✓ Excellent for transient DBS pulses\n- ✓ Simple, physical interpretation\n- ✓ Localized detection (causal-friendly)\n- ✓ Very fast\n\n### Cons\n- ✗ May over-smooth oscillatory signals\n- ✗ Less effective for oscillatory artifacts\n- ✗ Window size very algorithm-dependent\n\n### Tuning for Stronger Attenuation\n\n```python\n# Multiple passes approach\nraw_clean = preprocessor.remove_artifacts_time_hampel(\n    raw_dbs,\n    window_sec=0.2,\n    n_sigmas=2.0,              # Lower threshold\n    attenuation_factor=3.0     # 3 passes instead of 1\n)\n```\n\n### Best For\n- Removing transient pulses or spikes\n- Real-time processing\n- Causal (streaming) applications\n- Preprocessing before spectral methods\n\n---\n\n## Comparison Workflow\n\n### Step 1: Quick Screening\n```python\n# Use Spectrum-Fit for fast assessment\nraw_clean = preprocessor.remove_artifacts_spectrum_fit(\n    raw_dbs,\n    f_target=7.0,\n    bandwidth=2.0,\n    attenuation_db=-60.0\n)\n```\n\n### Step 2: Baseline-Aware Refinement\nIf baseline available:\n```python\nfrom src.filters import BaselineReferencedFilter\n\nwiener_filter = BaselineReferencedFilter(\n    baseline_raw=raw_baseline,\n    dbs_freq=7.0,\n    harmonic_bandwidth=1.5,\n    alpha=1.5\n)\nraw_clean = wiener_filter.filter(raw_dbs)\n```\n\n### Step 3: Spectro-Spatial Analysis\nFor research requiring channel correlation:\n```python\nraw_clean = preprocessor.remove_artifacts_zapline(\n    raw_dbs,\n    f_target=7.0,\n    n_harmonics=10\n)\n```\n\n### Step 4: Multi-Method Ensemble\nCombine methods for robust removal:\n```python\n# Apply methods sequentially\nraw_clean = preprocessor.remove_artifacts_spectrum_fit(\n    raw_dbs,\n    f_target=7.0,\n    attenuation_db=-40.0  # Moderate first pass\n)\n\nraw_clean = preprocessor.remove_artifacts_freq_hampel(\n    raw_clean,\n    n_sigmas=3.0,\n    attenuation_db=-40.0  # Second pass for peak refinement\n)\n```\n\n---\n\n## Recommended Parameters by Use Case\n\n### Clinical Screening\n```python\nraw_clean = preprocessor.remove_artifacts_spectrum_fit(\n    raw_dbs,\n    f_target=7.0,\n    bandwidth=2.0,\n    attenuation_db=-60.0  #
