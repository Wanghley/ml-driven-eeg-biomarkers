## Method Selection Guide

### Choose This Method If:\n\n#### 🎯 Spectrum-Fit (Fastest, Strongest)\n- [ ] You want strong, consistent artifact removal\n- [ ] You don't have a baseline recording\n- [ ] You need predictable, reproducible results\n- [ ] Speed is important\n\n#### 🧠 Baseline-Referenced Wiener (Best Preservation)\n- [ ] You have a clean baseline recording (XUAWAKEPRE or XUSLEEP)\n- [ ] Preserving endogenous brain activity is critical\n- [ ] You want time-varying, adaptive filtering\n- [ ] Research requiring precise frequency analysis\n\n#### 🌐 Zapline+ (Spectro-Spatial)\n- [ ] You're working with multi-channel recordings\n- [ ] Channel correlation matters for your analysis\n- [ ] You have good computational resources\n- [ ] Advanced research requiring spatial filtering\n\n#### 📍 Freq-Domain Hampel (Peak Detection)\n- [ ] You have sharp, well-defined DBS harmonics\n- [ ] You want adaptive peak detection\n- [ ] Phase relationships are important\n- [ ] Clinical screening applications\n\n#### ⚡ Time-Domain Hampel (Pulses)\n- [ ] You need to remove transient, sharp pulses\n- [ ] Real-time or streaming processing\n- [ ] Computational efficiency is critical\n- [ ] Preprocessing before spectral methods\n\n## Parameter Quick Reference\n\n### Spectrum-Fit\n| Strength | `attenuation_db` | `bandwidth` | Use Case
