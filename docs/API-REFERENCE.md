# API Reference - DBS Artifact Removal Methods\n\n## High-Level API (Recommended)\n\n### EEGPreprocessor.remove_artifacts_spectrum_fit()\n\n```python\nraw_clean = preprocessor.remove_artifacts_spectrum_fit(\n    raw,                          # MNE Raw object\n    f_target: Optional[float] = None,  # Fundamental frequency (Hz), auto-detected if None\n    bandwidth: float = 2.0,       # Total bandwidth around each harmonic (Hz)\n    attenuation_db: float = -60.0 # Attenuation level (dB, more negative = stronger)\n)\n```\n\n**Returns**: MNE Raw object with DBS artifacts removed\n\n**Parameters**:\n- `raw`: Input EEG data (MNE Raw object, must be preloaded)\n- `f_target`: Fundamental DBS frequency in Hz (e.g., 7.0, 14.0)\n  - If None, auto-detected from filename (e.g., \"XUAWAKE7_...\" → 7.0 Hz)\n  - Range: 1-100 Hz\n  - Default: Auto-detect from filename\n- `bandwidth`: Total bandwidth around each harmonic for filtering (Hz)\n  - 1.5 Hz: Narrow, more focused (stronger effect on brain)\n  - 2.0 Hz: Standard, balanced (default)\n  - 3.0 Hz: Wide, smoother transitions (lighter effect)\n  - Range: 0.5-5.0 Hz\n- `attenuation_db`: Target attenuation level in decibels\n  - Values must be negative (e.g., -60 means ~99.9% power reduction)\n  - -40 dB: Light (removes ~99% of harmonic power)\n  - -60 dB: Moderate (removes ~99.9%)\n  - -80 dB: Strong (removes ~99.99%)\n  - -100 dB: Maximum (removes ~99.999%)\n  - Range: -30 to -100 dB\n  - Default: -60 dB\n\n**Example - Default**:\n```python\nraw_clean = preprocessor.remove_artifacts_spectrum_fit(raw_dbs)\n```\n\n**Example - Strong removal**:\n```python\nraw_clean = preprocessor.remove_artifacts_spectrum_fit(\n    raw_dbs,\n    f_target=7.0,\n    bandwidth=1.5,\n    attenuation_db=-80.0\n)\n```\n\n**Example - Light removal**:\n```python\nraw_clean = preprocessor.remove_artifacts_spectrum_fit(\n    raw_dbs,\n    f_target=7.0,\n    bandwidth=3.0,\n    attenuation_db=-40.0\n)\n```\n\n---\n\n### EEGPreprocessor.remove_artifacts_zapline()\n\n```python\nraw_clean = preprocessor.remove_artifacts_zapline(\n    raw,                              # Threshold for artifact detection\n)\n```\n\n**Returns**: MNE Raw object with spatially-filtered artifacts removed\n\n**Parameters**:\n- `raw`: Input EEG data (MNE Raw object, multi-channel recommended)\n- `f_target`: Fundamental DBS frequency in Hz\n  - Auto-detected from filename if None\n  - Range: 1-100 Hz\n- `n_harmonics`: Number of harmonics to analyze\n  - 10: Standard (covers up to 70 Hz for 7 Hz fundamental)\n  - 5: Fewer harmonics (faster, less coverage)\n  - 20: More harmonics (slower, extensive coverage)\n  - Range: 1-20\n  - Default: 10\n- `threshold_percentile`: Percentile threshold for artifact detection\n  - 90.0: Aggressive (more removal, higher signal distortion)\n  - 95.0: Balanced (default)\n  - 98.0: Conservative (less removal, better preservation)\n  - 99.0: Very selective (minimal removal)\n  - Range: 80-99\n  - Default: 95.0\n\n**Example**:\n```python\nraw_clean = preprocessor.remove_artifacts_zapline(\n    raw_dbs,\n    f_target=7.0,\n    n_harmonics=10,\n    threshold_percentile=95.0\n)\n```\n\n---\n\n### EEGPreprocessor.remove_artifacts_freq_hampel()\n\n```python\nraw_clean = preprocessor.remove_artifacts_freq_hampel(\n    raw,                          # MNE Raw object\n    window_hz: float = 2.0,       # Frequency window size (Hz)\n    n_sigmas: float = 3.0,        # Sensitivity threshold (MAD units)\n    attenuation_db: float = -60.0 # Attenuation level (dB)\n)\n```\n\n**Returns**: MNE Raw object with spectral peaks attenuated\n\n**Parameters**:\n- `raw`: Input EEG data (MNE Raw object, preloaded)\n- `window_hz`: Window size for rolling median in frequency domain\n  - 1.0 Hz: Narrow (detects sharp peaks, may miss broad features)\n  - 2.0 Hz: Standard (default)\n  - 3.0 Hz: Wide (smoother, misses narrow peaks)\n  - Range: 0.5-5.0 Hz\n  - Default: 2.0\n- `n_sigmas`: Sensitivity threshold in Median Absolute Deviation (MAD) units\n  - 2.0: Aggressive (detects more, including weak peaks)\n  - 3.0: Balanced (default)\n  - 4.0: Selective (high threshold, misses subtle peaks)\n  - 5.0: Very selective (only obvious peaks)\n  - Range: 1.0-6.0\n  - Default: 3.0\n- `attenuation_db`: Target attenuation for detected peaks\n  - Same as Spectrum-Fit (-40 to -100 dB)\n  - Default: -60 dB\n\n**Example - Aggressive**:\n```python\nraw_clean = preprocessor.remove_artifacts_freq_hampel(\n    raw_dbs,\n    window_hz=1.0,    # Narrow\n    n_sigmas=2.0,     # Lower threshold\n    attenuation_db=-80.0  # Strong\n)\n```\n\n**Example - Conservative**:\n```python\nraw_clean = preprocessor.remove_artifacts_freq_hampel(\n    raw_dbs,\n    window_hz=3.0,    # 2.5 passes\n)\n```\n\n---\n\n### EEGPreprocessor.remove_artifacts_advanced()\n\n```python\nraw_clean = preprocessor.remove_artifacts_advanced(\n    raw,              # MNE Raw object\n    method: str,      #
